# Moonwalk 2.0

Scrolling research site for Moonwalk 2.0 — towards a permanent human presence on the Moon.
Phase 0 work at the Space Robotics Lab, Tohoku University.

- Zooming tour of the lunar south-pole base site
- Osteomorphic block explorer (Dyskin et al. 2003 geometry), with mass and payload checks and STL/GLB import
- End-effector options animated on the block: flush side handle, top twist-lock, top pocket grip
- Isaac Sim results dashboard (reads a results CSV; ships with illustrative placeholder data)

Live site: https://arhimatrix.github.io/arhimatrix-moonwalk-2-rep_01/

Moon surface map: Celestia (Clementine/NASA data). Relief map: Stellarium. 3D: three.js r128.
